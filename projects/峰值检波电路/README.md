# 峰值检波电路设计

## 项目简介
《高频电子线路》期末设计作业：设计一个二极管峰值（包络）检波电路，给出原理图与可打样的 PCB 全套文件。

## 设计指标（题目未给，自行设定并在说明中注明）
- **载波频率**：1 MHz
- **调制信号**：1 kHz
- **检波二极管**：肖特基 1N5711（低导通压降、高频特性好）
- **负载**：R = 10 kΩ、C = 10 nF，时间常数 RC = 100 µs，兼顾跟随包络与抑制载波纹波

## 技术栈
- **EDA**: KiCad 7
- **交付物**：原理图、50×40 mm 双层 PCB、Gerber + 钻孔文件、BOM、设计说明

## 技术亮点
1. **参数可算**：RC 取值按「远大于载波周期、远小于调制周期」的检波条件核算，不是随手凑数。
2. **可直接打样**：Gerber 与钻孔文件齐全，拿到嘉立创等平台即可下单。
