# 插排的最后一夜（AI 安全视频）

## 项目简介
「安全稳定大家谈」AI 生成视频作品征集（主题：AI 话安全 · 宿安伴我行）参赛作品。以一只拟人化的插排为主角，用它「最后一夜」的故事讲宿舍用电安全：过载、串联、私拉乱接这些日常隐患，最后都会算总账。

## 作品规格
- **时长**：128 秒
- **分辨率**：1920×1080（MP4）
- 带片名与字幕，全程 AI 生成 / 辅助制作
- **状态**：已提交（2026 年 11 月 22 日），待学院初评

## 创作说明
脚本与分镜先行，再逐镜生成画面并合成配音。返工主要花在配音上：合成语音出现过乱码与单音节循环，逐段重配、试听核对后才定版。成片的教训也很朴素——AI 生成的东西，交付前必须自己完整看一遍、听一遍。
