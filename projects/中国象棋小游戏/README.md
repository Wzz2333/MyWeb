# 中国象棋小游戏

## 项目简介
一个能在浏览器里直接开局的中国象棋小游戏，玩家执红与电脑对弈。纯前端单文件实现，无需安装、打开即玩。

## 技术栈
- **前端**: HTML + CSS + JavaScript（单文件）
- **部署**: GitHub Pages

## 功能特性
### 完整规则引擎
走法合法性、将军判定、将帅照面、胜负判定一应俱全，规则经过 22 项自动化测试校验。

### 电脑 AI
第一版电脑只会「看一步吃子」，被评价为太笨。升级后改为**位置表评估 + Alpha-Beta 剪枝多步搜索**：迭代加深，常规局面算 4 层、残局算 5 层，带静态搜索处理吃子交换，每步思考上限约 2.5 秒。用三道战术题（免费吃车、有毒兵不贪吃、红黑镜像）与自对弈全程合法性做过验证。

## 技术亮点
1. **搜索与规则解耦**：快速判将与快速走法生成让搜索速度撑得起 4~5 层深度。
2. **单文件交付**：整个游戏就是一个 HTML 文件，托管在 GitHub Pages 上。
