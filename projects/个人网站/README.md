# 个人网站 synuwz.online

## 项目简介
就是本站。王一止的个人网站，托管在 GitHub Pages，从 2026 年 11 月初开始持续迭代——它不像一次做完的作业，更像一间慢慢装修的屋子。

## 技术栈
- **前端**: HTML + CSS（Tailwind + 自定义样式）+ JavaScript
- **托管**: GitHub Pages + 自定义域名 synuwz.online
- **组件**: APlayer（开源音乐播放器，MIT）

## 功能特性
### 深空星野背景
Canvas 实时绘制：三团星云、约 170 颗远近两层闪烁的星星，与两条李萨如曲线（3:2 信号蓝、5:4 暖金）——简谐振动合成轨迹，算是给本专业留的一个小签名。

### 音乐台
左下角玻璃音乐按钮，点开是播放器加搜歌：预置公共领域 / CC 授权曲目，搜歌接 Internet Archive 开放音频库，点结果即播；播放器会记住上次的曲目与进度。

### 博客与荣誉墙
Markdown 文章系统（posts.json 索引 + 文章文件），含 RSS；荣誉墙收录证书 17 项，支持点击看大图。全站图片经压缩与懒加载，总量约 3MB。
