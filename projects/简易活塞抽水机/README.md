# 简易活塞抽水机

## 项目简介
沈阳师范大学「巧具名师」教具制作大赛命题组作品，面向初中物理「大气压强」一课。用 PVC 管、活塞与单向阀复现经典的活塞式抽水机，让学生亲眼看见：水不是被「吸」上来的，而是被大气压压上来的。

## 教学三件套
### 大气压强
抽水时活塞上提，筒内气压降低，外界大气压把水压进筒内、再压上出水口。一个标准大气压理论上最多把水压高约 10.3 米，这是这台教具最想让学生记住的数字。

### 单向阀
进水阀与活塞阀只许水往一个方向走，活塞上提进水、下压出水，两个阀门交替开合，抽水才能连续。

### 省力杠杆
压杆是一根杠杆：支点在一端，动力臂大于阻力臂，按压省力，代价是手要多走一段距离——省力不省功，顺带把杠杆原理也讲了。

## 制作材料
以 PVC 管为主体搭建，配活塞、密封圈与单向阀，结构透明直观，成本低、可复制，适合课堂演示与学生动手复刻。
